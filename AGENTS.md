# AGENTS.md

Cross-tool instructions for any AI coding assistant working in this repository.

For the full project rules—including session start, sprint workflow, folder ownership, code rules, and testing protocol—see [CLAUDE.md](CLAUDE.md). Everything there applies to every assistant.

## Read Aloud Report

End every response that completes meaningful repository work with a final section headed exactly `## 🔊 Read Aloud`.

- Use plain spoken prose only in that section: no bullets, code, raw paths, or emoji in the spoken text.
- Spell filenames and sprint numbers for speech.
- Summarize what was requested, changed, verified, and what remains open.
